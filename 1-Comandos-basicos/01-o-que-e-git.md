# 01 - O que é Git?

## 🧠 Definição

O **Git** é um **sistema de controle de versão distribuído** criado por Linus Torvalds em 2005 para gerenciar o desenvolvimento do kernel do Linux. Com ele, é possível acompanhar todas as alterações feitas em um projeto ao longo do tempo, colaborando com outras pessoas de maneira eficiente e segura.

---

## 📦 O que é controle de versão?

Controle de versão é a prática de registrar, acompanhar e gerenciar as alterações feitas em arquivos de um projeto. Isso permite:

- Acompanhar o histórico de modificações.
- Reverter para versões anteriores.
- Trabalhar com múltiplas versões de um mesmo projeto.
- Colaborar com outras pessoas de forma organizada.

---

## 🚀 Por que usar Git?

| Vantagem                        | Descrição                                                                 |
|--------------------------------|---------------------------------------------------------------------------|
| Histórico completo             | Armazena todas as versões do projeto.                                    |
| Trabalhar offline              | Você pode usar Git mesmo sem internet.                                   |
| Ramificações (branches)        | Permite criar versões paralelas para desenvolver novas funcionalidades.   |
| Facilidade de colaboração      | Desenvolvedores podem trabalhar juntos sem sobrescrever o código alheio. |
| Segurança e rastreabilidade    | Cada alteração tem um autor e data registrados.                          |

---

## 🗂️ Git vs GitHub

É comum confundir Git com GitHub, mas são coisas diferentes:

| Ferramenta | O que é                                       |
|------------|-----------------------------------------------|
| **Git**    | Ferramenta de linha de comando para controle de versão. |
| **GitHub** | Plataforma online para hospedar repositórios Git, colaborar com times e publicar código. |

Outras plataformas que também usam Git:
- GitLab
- Bitbucket
- Azure DevOps

---

## 🎯 Em resumo

- Git é uma ferramenta que **controla versões** do seu código.
- Ajuda a evitar perda de trabalho, facilita testes e garante rastreabilidade.
- É essencial para quem trabalha com desenvolvimento de software, pesquisa, ciência de dados ou qualquer projeto com código-fonte.
