# 📘 Curso de Git e GitHub para Iniciantes

Este repositório foi criado com o objetivo de oferecer um material **didático, progressivo e completo** para quem deseja aprender **Git e GitHub** do zero até a prática profissional. Ele é voltado especialmente para **alunos de cursos técnicos e superiores**, mas também pode ser utilizado por qualquer pessoa interessada em versionamento de código e colaboração em projetos.

---

## 🎯 Objetivos do Curso

- Ensinar o que é o Git, como funciona e por que é tão importante.
- Mostrar como instalar e configurar o Git corretamente.
- Apresentar comandos essenciais para o uso no dia a dia.
- Explicar como trabalhar com branches e fluxos de trabalho (workflow).
- Demonstrar boas práticas com commits semânticos.
- Ensinar como colaborar com outras pessoas usando GitHub.
- Introduzir o conceito de versionamento semântico (SemVer).

---

## 🧭 Estrutura do Repositório

Este repositório está organizado em **módulos numerados**, seguindo uma ordem pedagógica. Cada módulo contém **arquivos `.md`** com explicações simples, exemplos e comandos práticos.

### 📂 Módulos

| Nº | Módulo                      | Conteúdo Principal                                           |
|----|-----------------------------|--------------------------------------------------------------|
| 1️⃣ | Comandos Básicos             | O que é Git, instalação, configuração e comandos essenciais. |
| 2️⃣ | Fluxo de Trabalho            | Branches, Git Flow, GitHub Flow, merge, rebase e conflitos.  |
| 3️⃣ | Commits Semânticos           | Como escrever commits claros e padronizados.                 |
| 4️⃣ | Colaboração                  | Fork, clone, pull request, revisão de código.                |
| 5️⃣ | Versionamento Semântico      | Controle de versões com MAJOR, MINOR e PATCH.               |
| 6️⃣ | Extras                       | Glossário, dicas de ferramentas e atividades simuladas.      |

---

## 📝 Como Usar Este Repositório

1. **Leia os arquivos na ordem dos diretórios.** Cada módulo é numerado para facilitar seu avanço.
2. **Experimente os comandos no terminal.** Praticar é essencial para aprender Git.
3. **Use os exemplos como referência.** Eles foram escritos pensando no aluno iniciante.
4. **Explore o GitHub.** Faça forks, abra issues e pull requests neste repositório.

---

## 🧰 Requisitos

- Ter um terminal (Linux, macOS ou Git Bash no Windows).
- Ter o Git instalado (ver módulo 1 - Instalação).
- Conta no GitHub (gratuita).
