# 03 - Exemplos na Prática: Commits Semânticos

Neste arquivo, veremos exemplos reais de situações comuns em projetos de desenvolvimento e como escrever commits semânticos adequados para cada uma delas.

---

## 🧪 Cenário 1: Criação de uma nova funcionalidade

**Situação**: Você criou uma nova tela de cadastro de usuários.

**Commit semântico:**
```bash
feat(cadastro): adicionar tela de cadastro de usuários
```

---

## 🔧 Cenário 2: Correção de bug

**Situação**: Corrigiu o erro onde senhas fracas eram aceitas.

**Commit semântico:**
```bash
fix(senha): corrigir aceitação de senhas fracas no formulário
```

---

## 📚 Cenário 3: Alteração na documentação

**Situação**: Atualizou o README com novas instruções de instalação.

**Commit semântico:**
```bash
docs(readme): atualizar instruções de instalação
```

---

## 🎨 Cenário 4: Ajuste de estilo no código

**Situação**: Corrigiu identação e removeu espaços em branco.

**Commit semântico:**
```bash
style(home): ajustar identação e remover espaços desnecessários
```

---

## 🧼 Cenário 5: Refatoração de código

**Situação**: Separou a lógica de autenticação em uma função externa.

**Commit semântico:**
```bash
refactor(auth): extrair lógica de autenticação para helper
```

---

## 🚀 Cenário 6: Otimização de performance

**Situação**: Otimizou o carregamento das imagens da galeria.

**Commit semântico:**
```bash
perf(galeria): otimizar carregamento das imagens
```

---

## 🧪 Cenário 7: Adição de testes automatizados

**Situação**: Criou testes unitários para a função de login.

**Commit semântico:**
```bash
test(login): adicionar testes unitários da função de autenticação
```

---

## 🗃️ Cenário 8: Atualização de dependência

**Situação**: Atualizou o pacote `axios` para uma nova versão.

**Commit semântico:**
```bash
build(deps): atualizar axios para versão 1.4.0
```

---

## 🧹 Cenário 9: Limpeza de código

**Situação**: Removeu código comentado e variáveis não utilizadas.

**Commit semântico:**
```bash
cleanup(api): remover código morto e variáveis não usadas
```

---

## 🗑️ Cenário 10: Remoção de funcionalidade

**Situação**: Removeu a funcionalidade de chat por tempo indeterminado.

**Commit semântico:**
```bash
remove(chat): excluir módulo de chat obsoleto
```

---

## 🎯 Conclusão

Esses exemplos mostram como aplicar os commits semânticos em diferentes situações do dia a dia. Usar esse padrão melhora a comunicação entre os membros do time e deixa o histórico do projeto mais claro e profissional.
