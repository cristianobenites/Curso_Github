# 📚 Glossário de Termos Git e GitHub

Este glossário reúne os principais termos utilizados ao longo do curso, com explicações simples e diretas para facilitar o aprendizado.

---

### ✅ Git
Sistema de controle de versão distribuído que permite registrar o histórico de alterações em projetos de forma segura e colaborativa.

### ✅ GitHub
Plataforma online baseada no Git que permite hospedar repositórios, colaborar em equipe, revisar código e contribuir com projetos públicos ou privados.

### ✅ Commit
Registro de uma ou mais alterações feitas no projeto, acompanhado de uma mensagem descritiva.

### ✅ Branch
Ramificação do projeto usada para trabalhar em funcionalidades de forma isolada. Pode ser fundida com a branch principal (geralmente `main`).

### ✅ Merge
Comando que une o conteúdo de uma branch a outra.

### ✅ Rebase
Reorganiza o histórico de commits para que ele pareça mais linear, como se tivesse sido feito em sequência.

### ✅ Pull Request (PR)
Solicitação para integrar o conteúdo de uma branch (geralmente de um fork) ao repositório principal.

### ✅ Fork
Cópia de um repositório feita no GitHub, vinculada à conta do usuário. Permite que a pessoa trabalhe de forma independente.

### ✅ Clone
Cópia local de um repositório hospedado no GitHub para o seu computador.

### ✅ push
Envia as alterações locais (commits) para o repositório remoto (GitHub).

### ✅ pull
Atualiza seu repositório local com as mudanças mais recentes do repositório remoto.

### ✅ tag
Marcador usado para identificar versões específicas do projeto (ex: `v1.0.0`).

### ✅ release
Publicação formal de uma versão do projeto, geralmente associada a uma tag e um changelog.

### ✅ .gitignore
Arquivo onde você define quais arquivos ou pastas devem ser ignorados pelo Git (ex: arquivos temporários, senhas, dependências).

### ✅ log
Comando que exibe o histórico de commits de um projeto.

### ✅ status
Comando que mostra os arquivos modificados e prontos para commit.

### ✅ stage / staged
Arquivos que foram adicionados com `git add` e estão prontos para serem commitados.

### ✅ CI/CD
Integração contínua e entrega contínua: automação de testes, builds e deploys em projetos versionados.

### ✅ SemVer
Abreviação de Semantic Versioning: padrão de versionamento que usa MAJOR.MINOR.PATCH para indicar o tipo de alteração feita.

### ✅ Changelog
Arquivo que lista as mudanças feitas em cada versão de um projeto.

---
