# 🧪 Simulações para Praticar Git e GitHub

Este arquivo traz ideias de **atividades simuladas**, ideais para treinar os principais comandos e fluxos de trabalho com Git e GitHub, seja individualmente ou em grupo.

---

## 🔁 Simulação 1: Ciclo completo individual (CRUD de projeto local)

**Objetivo**: Praticar os comandos básicos de Git no terminal.

### Etapas:
1. Crie uma pasta local chamada `meu-projeto`
2. Inicialize com `git init`
3. Crie um arquivo `README.md` com um título
4. Faça `add`, `commit` e visualize com `git log`
5. Simule um erro, edite o arquivo e corrija
6. Faça novo commit com `fix:`
7. Crie uma branch `ajuste-texto` e edite o README
8. Faça merge com a branch `main`

---

## 👨‍👩‍👧‍👦 Simulação 2: Projeto em grupo com Pull Requests

**Objetivo**: Simular um time trabalhando em paralelo com branches e PRs.

### Etapas:
1. Uma pessoa cria um repositório e convida os demais como colaboradores
2. Cada integrante cria uma branch com seu nome e tema:
   - `ana/navbar`
   - `joao/footer`
   - `bia/login`
3. Cada um realiza commits semânticos com suas alterações
4. Todos abrem um Pull Request com explicação do que foi feito
5. Os colegas revisam os PRs (Code Review)
6. O dono do repositório aprova e faz merge na `main`

> Essa simulação pode ser feita via GitHub ou GitHub Classroom.

---

## 📦 Simulação 3: Versionamento com changelog e tags

**Objetivo**: Praticar controle de versões e changelogs.

### Etapas:
1. Em um projeto com histórico, adicione o arquivo `CHANGELOG.md`
2. Atualize a versão no `README.md` ou `package.json`
3. Use `git tag v1.0.0` e `git push origin v1.0.0`
4. Crie uma Release no GitHub com essa tag
5. Faça novas alterações e suba `v1.1.0`, `v1.1.1`, etc.

---

## 🌍 Simulação 4: Projeto público com Fork

**Objetivo**: Simular contribuição em um projeto open source.

### Etapas:
1. Faça fork de um repositório de exemplo
2. Clone na sua máquina
3. Crie uma branch `sugestao-ajuste`
4. Faça uma melhoria ou correção (ex: conserto de digitação)
5. Faça commit e push
6. Abra um Pull Request explicando sua sugestão

> Pode ser feito com repositórios didáticos, como os do próprio professor.

---

## 🧠 Dica final
