# 💡 Dicas e Ferramentas para Trabalhar com Git e GitHub

Nesta seção, você encontrará sugestões de ferramentas e boas práticas que vão facilitar muito seu dia a dia com Git e GitHub.

---

## 🛠️ Editores e IDEs

### ✅ Visual Studio Code (VS Code)
- Leve, rápido e com integração nativa com Git
- Extensões úteis:
  - GitLens: visualiza autorias e histórico de commits
  - Git Graph: visualização gráfica do repositório

### ✅ GitHub Desktop
- Ferramenta gráfica oficial da GitHub
- Ideal para iniciantes que não querem usar terminal

### ✅ GitKraken
- Interface visual avançada para gerenciamento de branches, merges e conflitos
- Grátis para uso pessoal e educacional

---

## 📦 Gerenciamento de Versões

### ✅ Semantic Release
- Gera changelogs e versões automaticamente com base nos commits semânticos

### ✅ Standard Version
- Similar ao semantic-release, mas manual

### ✅ Keep a Changelog
- Modelo oficial de changelog para seguir em projetos

---

## 🌐 Plataformas Integradas

### ✅ GitHub Actions
- Permite criar fluxos de CI/CD diretamente no GitHub
- Útil para:
  - Testes automáticos
  - Deploy automático
  - Análises de segurança e qualidade de código

### ✅ Netlify / Vercel
- Plataformas para deploy gratuito de sites hospedados em repositórios GitHub

## 📌 Boas práticas finais

- Faça commits pequenos e frequentes
- Use mensagens claras e semânticas
- Crie branches com nomes descritivos
- Sempre revise antes de fazer merge
- Evite “commits genéricos” como `ajustes` ou `atualizações`
- Trabalhe com Pull Requests, mesmo em projetos pequenos, para manter um bom histórico
